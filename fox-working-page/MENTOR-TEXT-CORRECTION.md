# Mentor-text selection correction

User direction, 6 September 2026: the library identifies the best examples in each book. It does not teach every skill through every book or populate every domain for completeness.

The previous local page substituted generic routines for located book examples. That was a regression from the intended product. The user-supplied `fox-book-detail.html` has now been read as text, with its archived PRIDE/inquiry screenshot inspected. Its specific examples establish the intended model, but its claims are not automatically verified.

## Required content order

1. Identify the exact scene, passage, language choice or illustrated moment. Use a scene locator when edition page numbers are unavailable.
2. Explain what makes this a particularly useful example of the selected skill or value. Merely being able to practise a skill while reading the book is insufficient.
3. Connect it to exact school curriculum wording at a justified level.
4. Build the teaching prompt from that evidence, then provide transfer to students' own work where appropriate.

A title-swapping check helps: if another title can be substituted without changing the explanation, the entry is probably too generic. Naming a character alone does not fix that. A reviewer must still judge whether the example is strong, accurate and worth recommending.

There are no minimum counts per book, domain or year. One excellent connection is useful. Zero is an acceptable result when evidence is insufficient. The active Fox page now contains three selected candidates: Fox's arrival for word choice; his final cry for inference; Magpie's decision to begin home for determination. Additional voice and inquiry drafts are held separately in `reserve-examples.json`, not displayed as recommendations. Prediction, oral language, vocabulary and fluency routines are retained only in the v1 archive.

## Source checks and corrections

The publisher's [Janet Anderson teaching notes](https://s3-ap-southeast-2.amazonaws.com/dimo.allenunwin.com/assets/teaching_resource/9781864489330.pdf) corroborate the arrival, departure/cry and ending. The editor's account supports examining the deliberate eye-description choice. The whole book has not been inspected; no edition page numbers or unseen illustration details have been invented.

The older prototype incorrectly names Kookaburra in multiple entries. Its speech-count and scar claims are not carried forward. Its broad assertions about unchanging tone, all readers' reactions and cultural interpretations are not treated as facts. Spotlight/pacing is not promoted without checking the relevant comparison. The short final-movement wording is traceable to the user-supplied prototype and remains marked for edition checking.

Original local v1 files are retained in `history/generic-v1/`. The v1 browser-storage key remains untouched; revised suggestions use a new key so old approvals cannot attach to changed content. No source vault file or live database record was changed. These three selections are draft recommendations, not teacher approvals.

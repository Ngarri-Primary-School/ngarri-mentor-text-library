# Big Red Kangaroo — OCR and visual review notes

**Source:** `Big Red Kangaroo.pdf` with companion file `BIG RED KANGAROO - text.pdf`
**Reviewed:** 9 September 2026

## What was checked

- The main PDF contains 36 pages; the story runs across PDF pages 9–29 with the information page on 31 and unrelated preview material on pages 34–36.
- The main PDF uses a custom-embedded display font that drops glyphs, so its text layer is only partly readable (clean fragments on pages 9–11, 13–17, 19–21, 25, 27–29, 31; blank or near-blank on 8, 12, 24, 32).
- Every checkable main-PDF fragment matches the companion teacher-text file word for word, so garbled passages were completed from the companion file.
- Factual side panels were kept in italics in narrative order.

## Scope decisions

The searchable transcript contains the story's continuous prose plus a short index of meaningful visual evidence. Dedication and imprint/copyright matter (pages 6–7), back-matter advertisements and the unrelated preview pages (34–36) were excluded from the story transcript.

## Confidence

Narrative text: high confidence — two independent sources agree everywhere both are readable. Pixel-level visual comparison against the rendered scans is still pending: the image-reading tool was unavailable during this pass, so a visual pass should be done before treating this transcript as final.

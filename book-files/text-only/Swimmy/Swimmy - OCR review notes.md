# Swimmy — OCR and visual review notes

**Source:** `Swimmy (Lionni, Leo, 1910-1999, author, artist) (Z-Library).pdf`
**Reviewed:** 9 September 2026

## What was checked

- The PDF contains 36 pages; the story runs across PDF pages 6–33.
- Story text was extracted from the embedded (born-digital) text layer and joined across line breaks.
- Punctuation, quotation marks, apostrophes and the SEE / THINK capitals were retained as embedded.
- Normalizations applied: page 9 layer reads "One bad day'a tuna fi§H" → transcribed "One bad day a tuna fish"; page 27 layer reads "I haye it!" → transcribed "I have it!".
- PDF page 18 (one marvel spread between the medusa and the strange fish) contains only garbled glyph fragments in the text layer — no story sentence is recoverable from the layer, and a bracketed placeholder marks the gap in the transcript. Do not fill it from memory; verify against the rendered scan.

## Scope decisions

The searchable transcript contains the story's continuous prose plus a short index of meaningful visual evidence. The Eric Carle tribute (page 3), dedication (page 4), title matter (page 5), publication data (page 34) and back-cover blurb (page 36) were excluded from the story transcript. Blank and illustration-only pages carry no text and contribute no prose.

## Confidence

Narrative text: medium-high confidence — the recoverable layer is clean, but one spread (page 18) is missing from the layer entirely and must be checked visually. Pixel-level visual comparison against the rendered scans is still pending: the image-reading tool returned an authentication error during this pilot, so a visual pass should be done before treating this transcript as final.

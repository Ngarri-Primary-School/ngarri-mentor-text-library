# Restricted reference archive

This directory preserves approved text-only source material so the private Ngarri project can continue if an external repository becomes unavailable.

## Handling rules

- Keep this repository private and limit access to authorised school project members.
- Use materials in the locations and formats approved by the school.
- Keep credentials out of this directory.
- Treat transcriptions as checking aids. Verify book-specific claims against the complete school-held copy and illustrations in `book-files/`.
- Use only short, necessary excerpts in teacher-facing analysis.

## JimK mentor texts

`jimk-mentor-texts/` contains the 98 Markdown documents copied from `filippo-cantone/jimk-library`, `content/Mentor Texts`, at source commit `5a6a6ea3c01b83b2dd97a6cec4a66580ab20cc46` on 10 September 2026.

`jimk-mentor-text-index.json` is the compact discovery index for those documents. It records the copied-text revision and, where available, a later JimK metadata revision that supplies genre and trait tags. Use it to find a possible transcript before extracting text; it does not replace checking the complete school book or applying Ngarri curriculum sources.

Only Markdown documents were copied. The source folder's embedded image assets were deliberately excluded.

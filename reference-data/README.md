# Structured reference data

This folder contains the structured reference files used to guide mentor-text content. These files were copied unchanged from the earlier project reference-data folder on 8 September 2026 so the school GitHub repository, rather than a private computer, holds the working reference set.

## Core Ngarri references

- `writing-throughlines.json` — seven writing traits with Foundation–Year 6 Key Understandings and Key Skills. The file identifies the source and distinguishes verbatim wording from recorded corrections.
- `reading-strategies.json` — reading-comprehension categories and strategy mappings across Foundation–Year 6.
- `inquiry-lenses.json` — the four Ngarri conceptual inquiry lenses, with source wording and derived selection indicators clearly distinguished.
- `pride-values.json` — Ngarri PRIDE definitions and behaviours, with derived selection indicators clearly distinguished.

These are the primary structured guides for matching book evidence to school curriculum, inquiry and values. A connection still requires teacher review and evidence from a verified complete book text.

## Supporting inventories and calibration

- `available-texts.json` — a dated inventory of texts that were available on the original Mac. Its local base path is provenance, not a portable or current storage location.
- `oz-lit-calibration.json` — consolidated secondary calibration data from the identified Oz Lit Teacher recommendation source.
- `oz-lit-stage-1.json` through `oz-lit-stage-4.json` — staged extraction records retained to show how the consolidated calibration file was assembled.

Oz Lit data is a secondary recommendation and comparison source. It does not replace Ngarri curriculum wording, direct inspection of a book, or teacher approval.

## Coverage and source handling

This is a verified reference set, not a claim that every potentially useful school or professional document has been collected. Add further reference material only after recording its source, version, ownership, extraction method and review status.

Do not add full commercial books, complete copyrighted professional-reading PDFs, credentials or private storage links. Prefer structured extracts that contain only the material needed for this project and preserve exact source wording separately from derived guidance.

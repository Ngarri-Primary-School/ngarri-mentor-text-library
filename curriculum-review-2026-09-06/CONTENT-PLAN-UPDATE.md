6 September 2026. Working interpretation for the Ngarri Mentor Text Library. Book connections and teaching ideas remain drafts until reviewed.

The library should help a teacher select a worthwhile learning opportunity, with the school's wording beside a practical example. These documents let us make that connection more precise and broaden it to oral language, vocabulary and fluency.

## Inquiry: possibilities that teachers can develop

Murdoch's discussion of conceptual contexts and compelling questions (printed pp. 40, 48) and flexible planning (printed pp. 76–81) supports a responsive approach. Teachers establish worthwhile conceptual and learning intentions, listen to students' thinking, and adapt the investigation. The phases can be revisited. A picture book can contribute to an inquiry without supplying an entire unit.

The school's short summary names five phases: Tuning In; Finding Out; Sorting Out; Going Further; Reflection & Action. Use these names when describing possible classroom uses. Do not require every book to have an activity for every phase. Reflection can occur throughout; action should arise meaningfully from learning.

A useful book inquiry entry should contain:

| Teacher-facing element | What to prepare |
|---|---|
| School lens | Existing school lens and its source definition |
| Conceptual connection | A specific concept and book evidence supporting it |
| Possible inquiry question | An open question labelled as a suggestion, with room for students to reshape it |
| How this book could help | One or two worthwhile uses within the inquiry phases |
| Listen for | What students say, do or create that could show developing understanding |
| Where it might lead | Optional further investigation or application, responsive to student questions |

The earlier plan treated a separately supplied official Big Question list as a prerequisite. That is no longer a necessary blocker for drafting. No such list has been established by these sources, and suggested questions must not be attributed to Ngarri or Murdoch as quotations. Any later school question list can be added with its own provenance.

Keep the conceptual inquiry intention distinct from the English skill. For example, investigating how relationships change is a conceptual direction; revising a prediction using evidence is a reading skill. They can support each other without becoming interchangeable labels. Avoid leading pupils toward a single predetermined moral.

## Comprehension: retain both frameworks

The recovered database has eleven reading strategies. The new document has four broader groups. The table below is a proposed relationship, not permission to merge references or automatically transfer year levels.

|---|---|---|
| Self-monitoring | Monitoring and self correcting | Compare the exact year-specific skill |
| Summarising | Literal knowledge/comprehension | Strong relationship; source wording still differs |

| Synthesising | Verbal and written text responses; Literal knowledge/comprehension | Appears in different forms and years |

| Questioning | No direct named equivalent | Do not infer a replacement from answering literal questions |

These are supplied school planning documents. Their condensed wording is not being certified as verbatim official Victorian Curriculum wording. Preserve the existing strategy IDs and every existing teacher/OzLit annotation. Store any future relationship separately with both source versions, the exact skills compared, a rationale and review status.

**Fox example:** the recovered Year 3 inference reference names character traits. The new document explicitly names traits, motives and perspectives in Year 4; its Year 3 column includes confirming or modifying predictions using evidence. This is a difference in source placement, not a claim that Year 3 children must not infer. The updated Fox example offers both pathways and identifies their sources.

## Broader English opportunities

Use the new speaking/listening, vocabulary and fluency references when the book and proposed task support them. Each teaching idea should link to an exact year-specific skill and explain how students will practise it. A discussion is not automatically evidence of every speaking skill.

Phonological awareness and phonics require a separate fit check against the words or sounds selected, students' needs and the school's teaching sequence. A rich teacher read-aloud is not automatically a decodable text. The library must distinguish listening to a book, supported excerpt practice and independent reading.

The new files do not revise the seven writing traits or five PRIDE definitions. Preserve those sources. Inquiry connections, values and writing craft each need their own evidence; a relationship theme alone does not establish all three.

## How to carry this into production

Keep the 77 extracted references as a versioned source set. Draft new examples against these exact cells while recording any differences from recovered references. Resolve conflicts before any replacement or curriculum migration. A proposed curriculum link needs source ID, year, selected skill, book evidence, explanation and reviewer decision.

Use the accompanying [Fox addendum](../fox-content-review/FOX-INQUIRY-AND-LITERACY-ADDENDUM.md) to calibrate the content. Select classroom passages before approving passage-specific claims. Then prepare the twenty-book benchmark using the same evidence and review format. Existing approval requirements for a collection-wide run remain in place.

AI suggestions remain available only for review until approved for the teacher library. These local planning files do not constitute publication approval. No new database content, schema change or paid generation run was performed in this review.
